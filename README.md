# Snake Game con React + Vite

## Descripción

Juego clásico de Snake desarrollado con React y Vite. El proyecto está dividido en componentes reutilizables y utiliza estado de React para manejar la lógica del juego.

## Tecnologías usadas

- React
- Vite
- JavaScript
- CSS

## Instalación

```bash
npm install
```

## Ejecutar el proyecto

```bash
npm run dev
```

## Cómo jugar

- Usa las flechas del teclado para mover la serpiente.
- Come la comida para crecer y aumentar el puntaje.
- Evita chocar contra las paredes o contra tu propio cuerpo.
- Si pierdes, puedes reiniciar el juego.

## Componentes principales

- App
- Board
- Snake
- Food
- Score
- GameOver
- StartScreen

## Extras implementados

- Pantalla de inicio.
- Pantalla de game over con reinicio.
- Aumento progresivo de dificultad.
- Estilo visual retro arcade.
